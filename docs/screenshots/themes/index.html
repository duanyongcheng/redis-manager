Redis Manager · 主题

一套界面，四种语言

同一套信息架构、同一套 Go 服务，四套主题只通过设计 token 与结构轴（页签形态、数据类型标签、进度条、侧栏、窗口）改变视觉语言。截图为应用真实渲染，数据来自 ?preview=1 的演示夹具。

C · Data console

Console

深色高密度仪表盘，珊瑚色点缀，等宽数字，常驻上下文条与 ⌘K 命令面板。最适合需要一屏看尽指标的后端与 DBA。

A · Terminal

Terminal

全等宽字体、琥珀荧光、ASCII 方框与 █░ 进度条，0 圆角。对 redis-cli 用户零学习成本。

B · Craft

Craft

暖纸色底、衬线标题、1px 细线与大留白，KPI 由卡片变成编辑式分栏。长时间阅读最不累。

D · Airy

Airy

桌面壁纸上的悬浮圆角窗口、毛玻璃侧栏、紫粉渐变与柔和光晕。第一眼最友好，适合面向更多开发者的版本。
